# BrainBait — Daily Supervisor Reports

Autonomous YouTube Shorts production for **BrainBait** ([@brainbait22](https://www.youtube.com/@brainbait22)).
One new Short per day, QC-gated, published automatically. This page carries the
machine-written supervisor report after every run, for review by Axel/ChatGPT.

- **[Latest report](latest.md)** — always the most recent run
- [Past reports](https://github.com/brainbait-reports/daily-reports/tree/main/reports) — one file per day

Reports contain operational data only: video IDs, titles, QC results, publish
status, and usage estimates. They never contain credentials, tokens, or
personal information — every report is machine-scanned for secrets before
publishing.
